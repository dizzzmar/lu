# Lucía Clavijo brand assets

Original client-supplied PNG files from Archivo.zip are preserved in originals/.

- LOGO_LU.png: white scissors and star; main site identity.
- LOGO_WHITE.png: white standalone star.
- LOGO.png: black standalone star.

The artwork has not been redrawn or generated. Web derivatives only remove transparent padding and resample the original pixels. Scissors alpha crop: (92,477) to (1776,1313). Star alpha crop: (133,185) to (1740,1688). The main scissors export is 1024×508; standalone stars are 512×479.

Dark-on-light menu branding uses CSS brightness(0) on the supplied white silhouette. Favicons use the original star on solid cream or black. The ICO contains 16, 32 and 48px images; Apple touch icon is 180px; manifest icons are 192 and 512px. The 1200×630 social preview combines the original scissors mark with the site's name and typeface. Icon padding is deliberate for small-size legibility.

The absolute social-preview URL in index.html must be updated if a custom domain is introduced. The manifest declares browser display mode; no offline/PWA capability is implied.
